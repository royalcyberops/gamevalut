# GameVault

Steam-inspired game store demo (college mini-project) — PHP + MySQL, no frameworks.

## Run (XAMPP)
1. Start Apache + MySQL
2. Copy folder to `C:\xampp\htdocs\steam`
3. Import `database.sql` via phpMyAdmin into `gamevault_db`
4. Open `http://localhost/steam/index.php`

## Pages
- `index.php` — Home / catalogue
- `register.php` / `login.php` — Auth
- `booking.php` — Reserve game
- `dashboard.php` — My bookings
